头像照片存放说明
================

把两位人物的照片分别命名为以下文件名放到本目录，刷新页面即可生效
（无需修改任何代码；照片缺失时头像自动回退为 Emoji）：

  sun_xiaochuan.png     -> 孙笑川
  takaichi_sanae.png    -> 高市早苗

建议：
- 使用竖版、脸部清晰、尽量接近方形的照片，效果最佳。
- 推荐来源：Wikimedia Commons 等标注了自由授权（公有领域 / CC）的公开照片。
- 本项目为非商业同人娱乐作品；如使用受版权保护的照片，请自行确认授权，
  并在需要时保留署名。更多说明见首页「开发者声明」。

程序内头像尺寸约 100px 左右，建议照片不小于 300px，支持 jpg/png/webp。
