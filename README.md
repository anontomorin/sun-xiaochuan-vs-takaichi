# 😎 孙笑川大战高市早苗 👩‍💼

一个纯原生 **HTML5 + CSS3 + JavaScript ES6+** 编写的单机 1v1 回合制卡牌网页游戏。
玩家选择「孙笑川」或「高市早苗」与 AI 对战，互相出牌、叠状态、放大招，直到一方 HP 归零。

> **作者：anontomorin** ｜ 非商业、娱乐向同人项目，v2.0

## ✨ 运行方式

**直接双击 `index.html` 即可运行。**

打开后会先进入**游戏首页**（封面 + 入口）：

- 「🎮 开始游戏」→ 角色选择 → 正式对战
- 「📜 开发者声明」→ 项目性质 / 人物梗说明 / 版权与免责声明

对局结束或返回角色选择页后，可随时「⌂ 首页」回到首页。

无需服务器、无需 npm、无需联网、无任何第三方依赖。支持桌面与移动端浏览器（Chrome / Edge / Safari / Firefox 等）。

> 提示：音效使用 Web Audio API 现场合成，无需任何音频文件；点按任意处即可解锁声音。

## 🎮 游戏规则

- 双方拥有固定 20 张牌组、10 点 AP 上限、开局 2 个通用道具；每轮先手由「当前有效速度」决定
  （更快者先出牌，同速轮流；速度会被状态影响：疾走 +25% / 减速 -25% / 增税负担 -30%）。
- 每个回合：+3 AP（「增税负担」-1）、抽 2 张、手牌上限 5（超出须弃牌），可自由保留未用完的 AP。
- 出牌：点击手牌查看详情并「出牌」；0 费防御牌（死猪不怕开水烫 / 政治正确）出牌后立即结束回合。
- 每回合 1 次「弃牌换 AP」：弃 1 张手牌 +1 AP。
- 道具（不耗 AP）：回血红包（+30% 最大 HP）、净化喷雾（清除负面状态）、能量咖啡（+2 AP）；使用后立即结束回合；「狗粉丝围攻」状态下禁用。
- 状态：同类不叠加、新覆盖旧；点击状态图标查看详情。「抽象化」状态下角色会失控随机行动，「台湾有事」会使技能牌 25% 概率哑火。
- 伤害：`(攻击-防御) × 倍率 × 随机系数(0.9~1.1)`，受增伤/减伤状态与 5% 暴击（×1.5）影响，最少 1 点。
- 胜负：任意一方 HP ≤ 0 立即结束。

## 🛠 技术栈

- 原生 HTML5 + CSS3 + JavaScript（ES6+，`const`/`let`、模板字符串、class 与模块化函数）
- 单一 `Game.state` 数据源，逻辑与 UI 分离（`game.js` 不直接操作 DOM）
- CSS 动画（攻击位移 / 受击抖动 / 伤害飘字 / 卡牌脉冲等），动画不阻塞战斗逻辑
- Web Audio API 合成音效（攻击 / 治疗 / 点击 / 胜利 / 失败）
- 响应式：支持 320 / 375 / 414 / 768 / 1024 / 1440 px，手牌区横向滚动，无整体横向溢出

## 🚀 部署到 GitHub Pages

本游戏为纯静态页面（无构建步骤、无后端、无联网请求），可直接托管到 GitHub Pages：

1. 在本目录初始化仓库并提交（已附 `.gitignore` 与 `.nojekyll`）：

   ```bash
   git init -b main
   git add .
   git commit -m "feat: 孙笑川大战高市早苗 - 回合制卡牌对战"
   ```

2. 在 GitHub 新建同名公开仓库 `sun-xiaochuan-vs-takaichi`（不要勾选自动生成 README）。

3. 关联并推送：

   ```bash
   git remote add origin git@github.com:<你的用户名>/sun-xiaochuan-vs-takaichi.git
   git branch -M main
   git push -u origin main
   ```

4. 开启 Pages：仓库 Settings → Pages → Source 选
   `Deploy from a branch` → 分支 `main` / 目录 `/(root)` → Save。

5. 访问：`https://<你的用户名>.github.io/sun-xiaochuan-vs-takaichi/`

> 说明：项目内全部资源使用相对路径（`css/`、`js/`、`assets/`），
> 部署在子路径下也能正确加载，无需修改任何代码。
